# message-sharing Specification

## Purpose

定义把消息转发到其他应用时的目标选择行为，包括常用应用的优先排序，方便用户快速找到微信、QQ、飞书等高频分享目标。

## Requirements

### Requirement: 常用分享应用优先展示

转发面板的“其他应用”列表 SHALL 优先展示常用应用，其余应用 MUST 排在常用应用之后。

#### Scenario: 常用应用排在前面
- **WHEN** 设备同时安装了微信、QQ、飞书与其他可分享应用
- **THEN** 微信、QQ、飞书依次出现在列表最前面
- **AND** 其他应用排在其后并按名称排序

#### Scenario: 未安装的常用应用不影响排序
- **WHEN** 设备未安装微信
- **THEN** 列表从已安装的常用应用中按既定顺序开始展示
- **AND** 其余应用仍然排在其后
