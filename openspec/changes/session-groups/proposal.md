# Proposal

## Why

当前对话列表没有分组，所有对话混在一起，无法把少数关键内容与随手草稿分开。用户需要首次安装即有“极其重要”和“草稿”两个分组，并把“草稿”作为初始选中项。

## What Changes

- 对话抽屉新增分组筛选：“极其重要”“草稿”，任一时刻选中一个分组，只显示该分组下的对话。
- 首次安装默认选中“草稿”；之后启动恢复最后一次使用的分组。
- 新建对话归入当前选中的分组；会话菜单新增“移到极其重要/移到草稿”。
- 分组归属与最后选中项保存在本机偏好，不写入记录文件、不参与局域网同步；未指定分组的对话视为“草稿”。

## Impact

- 新增 `SessionGroup`、`SessionGroupStore`（SharedPreferences）。
- `ChatViewModel` 增加分组状态与操作，`ChatScreen` 抽屉增加分组筛选与会话移动菜单。
- 不修改数据库结构、记录文件格式和同步协议。
