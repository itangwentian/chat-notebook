# Proposal

## Why

用户需要给具体消息设置到点提醒，但本项目是单机应用，没有服务器，也不接 FCM 或厂商推送通道。中国大陆的安卓设备上，FCM 不可用，厂商通道需要服务端与资质报备；因此提醒只能由设备本机在指定时间触发系统通知。

## What Changes

- 新增对话级与消息级的一次性提醒：可设置、修改、取消，并查看待触发提醒。
- 提醒随对话记录写入用户选择的目录（会话文件与快照），卸载重装后重新打开目录仍可恢复；局域网同步按 `updatedAt` 合并提醒，取消与触发状态作为墓碑传播。
- 使用 `AlarmManager` 精确闹钟触发本地通知，通知包含对话标题与消息摘要，点击后打开对应对话，并滚动到绑定消息、让其背景闪烁约 5 秒。
- 提醒到点时可感知：通知带默认提示音与震动，屏幕熄灭时点亮屏幕并在锁屏上展示提醒；系统允许时附带全屏意图，未授权时退回横幅通知。
- 已设置且尚未触发的消息提醒让消息气泡底色略微偏红以便识别，不额外绘制角标；取消、触发或过期后底色恢复。
- Android 13+ 请求 `POST_NOTIFICATIONS`，Android 12+ 检查精确闹钟能力；未获授权时降级为非精确闹钟并在界面明确提示，不静默失败。
- 设备重启、系统时间或时区变化、应用重新打开时重排尚未触发的提醒。
- 不使用服务端推送、FCM、厂商通道或第三方推送 SDK；不提供周期重复提醒。

## Capabilities

### New Capabilities

- `scheduled-reminders`: 对话与消息的本地定时提醒，包括提醒记录、闹钟调度、通知投递、权限处理与重启恢复。

### Modified Capabilities

- `lan-note-sync`: 同步载荷包含提醒，并在并发合并时按提醒标识取较新状态、保留取消墓碑。

## Impact

- 数据：`Snapshot.kt` 新增提醒记录并扩展快照与会话文件；`SnapshotCodec` 校验；`RecordDatabase` 新增提醒索引表与迁移。
- 同步：`SyncRecords`/`SyncConflicts` 增加提醒字段与合并规则，`LAN_SYNC_VERSION` 提升，旧版本与新版本混合配对会同步失败，需两端同时升级。
- Android 组件：`AndroidManifest.xml` 增加通知、精确闹钟、开机广播、唤醒锁与全屏意图权限以及广播接收器；新增通知渠道、提醒调度器与通知构建代码。
- 界面：对话抽屉菜单、消息操作菜单增加“设置提醒”，新增提醒时间选择与待触发提醒列表；`MainActivity` 处理通知点击的会话跳转。
- 测试：提醒合并、调度重排、权限降级的单元测试，以及模拟器上的通知触发与重启恢复验证。
