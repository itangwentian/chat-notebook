# Proposal

## Why

应用已接入 OpenAI 兼容的 LLM，但目前只在用户手动「整理对话」时使用，发送消息本身没有任何即时反馈。用户在对话里打字时容易留下错别字，也常在句子里顺带提到未来要做的事，却还要再长按气泡、手动填一次提醒时间。

需求方要求：在配置了 LLM 的情况下，对话界面以左侧气泡的形式回应用户刚发送的消息，提供错别字修正与提醒设置两类建议，用户一键采纳即可生效。

## What Changes

- 用户消息发送成功后异步发起一次建议分析，返回错别字修正与提醒意图；只有命中时才在该消息之后插入左侧建议气泡。
- 建议气泡是临时状态：只存在内存，不写入会话文件、快照或局域网同步载荷，重启后消失；采纳产生的后果才落盘。
- 错别字建议展示最小修正后的完整文本并高亮改动片段；采纳后通过现有编辑链路更新用户消息，并写入修改历史。
- 提醒建议展示识别出的时间；采纳后直接为该消息创建提醒，Android 13+ 缺少通知权限时先请求授权。
- 忽略建议即作废，不重新分析；消息被编辑或删除后对应建议自动失效。
- 语音转写不在本次范围内：实测当前模型通道会静默丢弃音频，且该服务没有转写端点。

## Capabilities

### New Capabilities

- `message-assists`: 基于 LLM 的逐条消息建议，包括分析触发条件、建议气泡、错别字采纳与提醒采纳。

### Modified Capabilities

- 无。建议气泡是独立组件，不改变既有消息气泡、提醒与同步的契约。

## Impact

- 数据：无新增持久化结构，不改 `Snapshot.kt`、不改 Room 版本、不改 `LAN_SYNC_VERSION`；采纳结果复用既有的编辑与提醒写入链路。
- AI：新增逐条建议的提示词与结果模型；`AiService` 增加建议方法，`OpenAiCompatibleClient` 复用于 JSON 输出。
- 界面：`ChatViewModel` 增加内存态建议集合，`ChatScreen` 在消息流中插入左侧建议气泡与小型操作按钮。
- 测试：建议解析、触发条件、采纳动作的单元测试，以及建议气泡与按钮的 Compose 界面测试。
