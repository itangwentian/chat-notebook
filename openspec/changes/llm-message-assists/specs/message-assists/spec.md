# Spec Delta

## Purpose

定义配置了 LLM 之后，对话界面对用户刚发送消息给出的即时建议：错别字修正与提醒设置。建议以左侧气泡呈现，只在用户采纳后改变已有记录。

## ADDED Requirements

### Requirement: 分析触发条件

应用 SHALL 仅在配置了可用 LLM（非 mock 模式且存在启用的默认模型配置）时，对用户新发送的消息发起一次建议分析。分析 MUST 在消息成功持久化之后进行，MUST NOT 阻塞或推迟消息发送。分析失败、超时或未命中任何建议时 MUST 静默结束，不出现占位、错误提示或重试入口。

#### Scenario: 未配置模型时不分析
- **WHEN** 应用处于 mock 模式或没有任何启用的模型配置，用户发送一条消息
- **THEN** 不发起分析请求，也不出现任何建议气泡

#### Scenario: 分析失败不打扰
- **WHEN** 分析请求返回错误、超时或内容无法解析
- **THEN** 消息正常显示，界面不出现建议气泡与错误提示

#### Scenario: 命中建议才插入气泡
- **WHEN** 分析返回错别字修正或提醒意图中的任意一项
- **THEN** 在该用户消息之后插入一个左对齐的建议气泡，其余消息布局不变

#### Scenario: 语音消息不分析
- **WHEN** 用户发送的是语音消息
- **THEN** 不发起建议分析，也不出现建议气泡

### Requirement: 错别字修正建议

建议气泡 SHALL 展示最小修正后的完整文本，并高亮被改动的片段。用户采纳后，应用 MUST 用修正文本更新该消息并写入修改历史，MUST 保持消息标识不变。用户忽略后，该建议 MUST 被丢弃，且不再基于同一内容重新出现。

#### Scenario: 展示修正建议
- **WHEN** 分析发现用户消息包含错别字
- **THEN** 左侧气泡显示修正后的完整文本，改动处高亮，并提供“采纳”与“忽略”两个按钮

#### Scenario: 采纳修正
- **WHEN** 用户点击“采纳”
- **THEN** 消息内容更新为修正文本，该消息的修改历史新增一条记录，气泡随即消失

#### Scenario: 忽略修正
- **WHEN** 用户点击“忽略”
- **THEN** 气泡消失，消息内容不变，且不会再为这条消息弹出同一建议

#### Scenario: 只改错别字
- **WHEN** 原文存在错别字
- **THEN** 修正结果只替换错别字，不改变语气、句子结构与标点风格

### Requirement: 提醒建议

建议气泡 SHALL 在用户消息表达了未来某个具体时刻要做某事时，提示是否创建日程，并显示识别出的触发时间。用户点击后 MUST 打开提醒创建面板并预填识别出的时间，由用户修改或确认后手动创建；应用 MUST NOT 在点击时直接创建提醒。

#### Scenario: 打开创建面板
- **WHEN** 用户点击“创建日程”
- **THEN** 应用打开提醒创建面板，日期与时间预填为识别出的时刻，此时尚未创建提醒

#### Scenario: 修改时间后创建
- **WHEN** 用户在面板中修改时间并确认
- **THEN** 应用按用户确认的时间为该消息创建提醒，原建议气泡消失

#### Scenario: 取消创建
- **WHEN** 用户在面板中取消
- **THEN** 不创建提醒，建议气泡保留

#### Scenario: 缺少通知权限
- **WHEN** 用户在面板中确认创建时系统尚未授予通知权限
- **THEN** 应用请求通知权限，提醒仍被创建，并以提示说明权限状态

#### Scenario: 识别时间不合法
- **WHEN** 识别出的时间不晚于当前时间或超出可接受范围
- **THEN** 该条建议不提供创建按钮，且不打开面板

#### Scenario: 消息已不存在
- **WHEN** 用户点击创建时该消息已被删除
- **THEN** 不打开面板、不创建提醒，气泡消失

### Requirement: 建议气泡的生命周期

建议气泡 SHALL 只是临时状态：MUST NOT 写入会话文件、快照或局域网同步载荷，MUST NOT 出现在导出与整理结果中，应用重启后 MUST NOT 恢复。建议 MUST 与消息的内容版本绑定，消息被编辑或删除后对应建议 MUST 失效。

#### Scenario: 重启后不恢复
- **WHEN** 用户在建议气泡出现后重启应用
- **THEN** 该建议不再出现

#### Scenario: 编辑后失效
- **WHEN** 建议气泡存在时该消息被其他入口修改
- **THEN** 原气泡消失，且不会基于旧内容执行采纳

#### Scenario: 不进入同步与导出
- **WHEN** 用户导出对话或与另一台设备同步
- **THEN** 传输内容不包含任何建议气泡

#### Scenario: 切换对话后仍可见
- **WHEN** 用户在建议未处理时切换到其他对话再切回
- **THEN** 未处理的建议仍然显示，已采纳或已忽略的不再出现
