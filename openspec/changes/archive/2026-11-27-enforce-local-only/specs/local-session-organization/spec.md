# Spec Delta

## Purpose

让会话整理完全在设备本地完成，用户无需任何配置即可把对话生成可保存、可阅读的整理文档。

## ADDED Requirements

### Requirement: 整理始终本地执行

会话整理 MUST 只使用本地代码生成文档，不依赖网络、外部服务或凭据。

#### Scenario: 触发整理

- **WHEN** 用户在任意会话中触发整理
- **THEN** 应用立即开始本地整理
- **AND** 不显示服务选择或网络请求状态

#### Scenario: 无网络整理

- **WHEN** 设备处于离线状态且用户触发整理
- **THEN** 整理仍能完成并生成整理文档

### Requirement: 本地整理文档结构

整理结果 SHALL 按消息时间升序排列，按自然日分组，并省略已删除、空白以及内容重复的旧消息，只保留重复内容中最新的一条。

#### Scenario: 同日多条消息

- **WHEN** 同一自然日内存在多条未删除且内容不同的消息
- **THEN** 文档以日期标题分组
- **AND** 每条消息按时间升序显示，并带有发送时间

#### Scenario: 重复内容

- **WHEN** 多条消息去除首尾空白与连续空白后内容相同
- **THEN** 文档只保留其中发送时间最新的一条

### Requirement: 整理结果标记本地来源

整理结果 SHALL 标明由本地整理生成，并记录参与整理的消息数量与时间范围。

#### Scenario: 查看整理结果

- **WHEN** 用户打开整理结果
- **THEN** 文档标头显示“本地整理”
- **AND** 显示消息条数以及开始与结束时间

### Requirement: 空会话不生成文档

没有可整理消息时，应用 MUST 拒绝生成空文档并向用户给出提示。

#### Scenario: 会话只有已删除消息

- **WHEN** 用户对仅含已删除消息的会话触发整理
- **THEN** 应用不生成整理文档
- **AND** 提示暂无可整理的消息
