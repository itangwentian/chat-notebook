# Spec Delta

## Purpose

保证用户在任一设备上修改对话名称后，名称能通过局域网同步传播到自己的另一台设备，并在对端列表与当前打开的对话中显示。

## ADDED Requirements

### Requirement: 仅修改对话名称也会同步

同步投影 SHALL 包含对话名称。仅修改对话名称（消息内容、附件和删除状态不变）时，系统 SHALL 推进本机该对话的同步版本，并在下一轮同步把新名称传播到已配对的对端，无需等待其他内容变化。收到名称变更的一端 SHALL 使用新名称更新会话列表和当前打开的对话标题。

#### Scenario: 发起端只改名
- **WHEN** 一端把已同步对话重命名并保存，另一台设备处于前台且网络可达
- **THEN** 对端在下一轮同步后显示新名称，消息与附件保持不变

#### Scenario: 对端只改名
- **WHEN** 非发起端把已同步对话重命名并保存
- **THEN** 发起端在下一轮同步后显示新名称，双方版本继续合并而不是重新传输正文

#### Scenario: 对端正打开该对话
- **WHEN** 对端正在查看被同步改名的对话
- **THEN** 会话列表和聊天界面的标题同步显示新名称，无需重新进入对话

#### Scenario: 两端同时改名
- **WHEN** 两端在未看到对方修改时分别重命名同一对话
- **THEN** 系统按既有并发冲突规则保留主版和带来源设备标记的副本，不因重复同步产生额外副本
