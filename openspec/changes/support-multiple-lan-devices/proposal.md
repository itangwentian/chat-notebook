# Proposal

## Why

当前局域网同步只保存一台“自己的设备”：完成一次配对后，设置页不再显示“显示二维码 / 扫码配对 / 从图片识别”，第三台设备无法再加入。用户需要在同一账号的多台设备之间同步，已配对设备也不能被新配对覆盖。

## What Changes

- 配对入口常驻：记录目录可用时始终显示添加设备入口，已配对后仍可扫码添加新设备。
- 信任列表：持久化多台已配对设备，新增设备不覆盖旧设备；保留旧版单设备数据的迁移。
- 多设备同步：对每台已配对设备分别建立局域网同步会话，交换过程串行执行，避免并发写入冲突。
- 设备管理：设置页列出已配对设备，可逐台移除；暂停/继续仍对所有设备生效。
- 最近成功时间继续全局展示。

## Impact

- 影响 `LanTrustStore`、`LanSyncManager`、`LanSyncStatus`、`LanSyncSection`。
- 不改变同步协议版本、数据格式和附件规则；旧设备无需升级即可继续与第一台设备同步。
- 不改变“未配对设备无法访问数据”的安全约束。
