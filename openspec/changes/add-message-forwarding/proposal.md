# Proposal

## Why

当前对话支持长按进入多选，但只能复制、删除或合并，无法把选中的聊天气泡转存到其他已有对话。用户需要在整理或迁移内容时，把一条或多条消息转发到另一个对话继续使用。

## What Changes

- 多选工具栏新增“转发”操作，选中一条或多条消息后可用。
- 点击后弹出目标对话选择框，列表只显示当前对话以外的未删除对话；没有其他对话时显示新建提示。
- 确认目标后，按原时间顺序把所选消息以新消息复制到目标对话，保留角色与当前可见正文；不复制引用、表情、气泡格式与 AI 结果。
- 转发完成后停留在当前对话，退出多选并提示“已转发 N 条消息到《目标对话》”。
- 源对话内容不变；目标对话的修改时间更新，修改时间排序下会上浮。
- 目标不存在、选中消息已变化或目标等于当前对话时返回中文错误。

## Capabilities

### New Capabilities

- `message-forwarding`：将当前对话选中的消息转发到其他已有对话。

## Impact

- 代码：`ChatSessionService`（新增复制转发）、`ChatRepository`、`ChatViewModel`、`ChatScreen`（多选操作与目标选择框）、`MainActivity`。
- 数据：不改变快照与 Room 结构；转发产生普通的新消息记录。
- 验证：服务层复制顺序与内容、ViewModel 转发流程、Compose 目标列表排除当前对话、模拟器端到端。
