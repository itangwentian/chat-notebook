# Spec Delta

## Purpose

调整整理文档的角色标注规则：阅读界面只保留 `『时间』` 与正文，不再区分用户、助手与系统。

## MODIFIED Requirements

### Requirement: 隐藏用户角色标签

整理文档 MUST NOT 显示任何角色标签：用户、助手与系统发言都只显示 `『HH:mm』` 时间前缀与正文，不出现“用户”“助手”“系统”等字样。发给模型的对话记录 MUST NOT 显示“用户”标签，助手与系统标签 MAY 保留用于模型理解上下文，但 MUST NOT 出现在整理文档与导出结果中。

#### Scenario: 用户发言
- **WHEN** 用户发送消息并生成整理文档
- **THEN** 该条只显示 `『时间』` 与正文，不出现“用户”

#### Scenario: 助手发言
- **WHEN** 对话包含助手回复
- **THEN** 整理文档只显示 `『时间』` 与正文，不出现“助手”标签

#### Scenario: 系统发言
- **WHEN** 对话包含系统消息
- **THEN** 整理文档只显示 `『时间』` 与正文，不出现“系统”标签
