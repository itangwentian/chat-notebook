# Proposal

## Why

整理结果页目前把时间作为单独一行加粗文字（本地整理输出 `**09:00**`，会话整理也未被要求固定结构），看起来像一级多余的小标题，层级与“对话名 → 日期 → 正文”不一致；助手与系统消息还会额外显示角色标签，干扰阅读。用户希望保留对话名大标题和日期小标题，把时间并入正文开头，并统一隐藏角色标注。

## What Changes

- 本地整理文档保持 `# 对话名` 与 `## yyyy年M月d日` 两级标题，删除单独的时间行，改为每条消息以 `『HH:mm』` 开头并与正文同段，例如 `『09:00』正文`。
- 整理文档不再输出“助手”“系统”等角色标签；用户、助手、系统消息统一只显示 `『时间』` 与正文。
- 整理文档固定使用同样的结构（对话名、日期小标题、`『HH:mm』` 正文，不输出角色标签）。
- 已保存的整理文档不迁移，重新整理或新整理后使用新格式；结果页渲染、导出能力与消息数据不变。

## Capabilities

### New Capabilities

- `organized-document-layout`: 整理文档的标题层级、日期分组与时间前缀排版规则，覆盖本地整理与整理规则要求。

### Modified Capabilities

- `document-markdown-formatting`: “隐藏用户角色标签”调整为整理文档隐藏全部角色标签（整理输入仍可保留助手/系统标签）。

## Impact

- 代码：`LocalSessionDocumentComposer.kt` 的逐条排版与角色标注；`SessionDocumentPrompt` 的系统提示词。
- 测试：整理文档与服务相关单元测试中的格式断言（时间行、角色标签、日期分组）。
- 兼容性：同步记录、附件、导出格式与结果页渲染不变；旧文档保持原样。
