# Spec Delta

## MODIFIED Requirements

### Requirement: 首次安装默认对话

记录目录中不存在本应用的记录数据（会话文件、设置文件、同步日志或旧版笔记文件）时，应用 SHALL 创建“极其重要”和“草稿”两个默认对话；目录中已有任一此类记录文件时，应用 MUST NOT 创建默认对话。目录中的无关文件或空子目录 MUST NOT 阻止默认对话创建。

#### Scenario: 首次打开应用
- **WHEN** 用户首次安装、选择一个空目录进入应用
- **THEN** 对话列表显示“极其重要”和“草稿”两个对话
- **AND** 两者都可以像普通对话一样收发消息、重命名与删除

#### Scenario: 目录含无关文件时仍创建
- **WHEN** 用户首次安装、选择一个已有无关文件（例如下载目录中的图片或文档）且没有本应用记录文件的目录
- **THEN** 对话列表显示“极其重要”和“草稿”两个对话

#### Scenario: 目录只有空子目录时仍创建
- **WHEN** 用户选择的目录中没有本应用记录文件，只有空的子目录
- **THEN** 对话列表显示“极其重要”和“草稿”两个对话

#### Scenario: 已有记录的目录不创建
- **WHEN** 用户重装后选择包含本应用记录文件（会话、设置、同步日志或旧版笔记）的目录
- **THEN** 应用不创建默认对话

#### Scenario: 重命名或删除默认对话后重装
- **WHEN** 用户重命名或删除默认对话，卸载重装后重新选择原目录
- **THEN** 目录中仍有本应用记录文件，应用不创建默认对话

#### Scenario: 删除后不自动重建
- **WHEN** 用户删除“极其重要”和“草稿”后重新打开应用
- **THEN** 应用不自动重新创建这两个对话
