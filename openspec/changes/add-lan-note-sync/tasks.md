实测修正了 Android Keystore 的 ECDSA 摘要配置及重启时 DNS-SD 缓存旧端口的问题。修正后完整单元测试 154 项通过，Lint、Debug APK、Release APK 构建及本变更的 OpenSpec 严格校验通过。
