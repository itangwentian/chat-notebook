# Proposal

## Why

聊天笔记目前依赖每台设备各自选择的本地记录目录。用户在两台安卓设备间切换时，需要能在同一局域网内自动交换新增、修改和删除的笔记。

## What Changes

- 增加默认关闭的局域网同步。一次扫码成功即将对端加入“自己的设备”，信任无到期时间。双方应用位于前台且在同一局域网可达时自动双向同步。
- 首版按对话比较版本和内容，仅交换新增或变更的对话、删除标记，以及接收端缺失的图片和语音附件。
- 同步包含对话标题、消息及其文本编辑和关系数据、已保存的整理文档。服务配置、凭据、草稿和设备状态留在各自设备。
- 首次同步保留双方已有笔记。两端离线修改同一对话时保留两版，遇到删除与编辑冲突时保留编辑副本。
- 在设置中提供扫码配对、暂停、移除设备、最近同步时间和失败原因。更换本机记录目录保留设备信任，同步改用当前选定的目录。

## Capabilities

### New Capabilities

- `lan-note-sync` 定义两台安卓设备的局域网配对、自动差异同步、删除和冲突处理。

### Modified Capabilities

## Impact

涉及设置界面、应用前台生命周期、局域网服务发现、设备身份凭据和记录仓库。用户选择的目录继续保存原有对话 JSON 和附件，附加版本和删除元数据，Room 继续作为可重建索引。发布版为局域网连接启用必要权限，外部服务开关维持关闭。
