# Proposal

## Why

当前气泡格式的加粗、倾斜、删除线是互斥单选，用户无法同时表达“既加粗又倾斜”这类常见强调。三种字体效果在语义上彼此独立，应该可以叠加。

## What Changes

- 加粗、倾斜、删除线改为复选：任一时刻可以同时启用其中任意组合，也可以全部取消。
- 字体效果与颜色仍可组合；颜色保持互斥单选。
- 格式标识允许同时包含多个字体效果（如 `bold+italic+red`），重复的字体效果或颜色视为无效。
- 旧格式标识（`bold`、`italic+red` 等）保持可解析，无需迁移历史数据。
- 气泡渲染与导出 Markdown 同时应用所有已选字体效果。

## Impact

- 修改 `BubbleFormat` 的数据模型、`toggleStyle` 与 `fromId` 解析。
- 修改 `ChatScreen` 的格式菜单选中态与文字渲染，以及 `MessageMarkdown` 的 Markdown 生成。
- 不修改数据库结构、记录文件格式与局域网同步协议。
