# Spec Delta

## Purpose

定义配置 LLM 后，对话界面对用户「查找历史消息」请求的意图识别、跨对话本地检索与可点击结果气泡，让用户能直接回到命中的对话与消息。

## ADDED Requirements

### Requirement: 搜索意图识别

应用 SHALL 仅在配置了可用 LLM（非 mock 模式且存在启用的默认模型配置）时，对用户新发送的纯文本消息判断是否在请求查找历史消息。识别 MUST 在消息成功持久化之后异步进行，MUST NOT 阻塞或推迟消息发送；未命中、请求失败或输出不合法时 MUST 静默结束，不出现气泡或错误提示。

#### Scenario: 命中搜索意图
- **WHEN** 用户发送「帮我找一下之前说过的报销」且模型将其识别为查找历史消息
- **THEN** 该消息之后出现搜索建议气泡，其余消息布局不变

#### Scenario: 普通消息不触发搜索
- **WHEN** 用户发送一条没有表达查找意图的消息
- **THEN** 不出现搜索建议气泡

#### Scenario: 未配置模型时不判断
- **WHEN** 应用处于 mock 模式或没有任何启用的模型配置，用户发送消息
- **THEN** 不发起意图判断请求，也不出现搜索气泡

#### Scenario: 意图分析失败不打扰
- **WHEN** 意图判断请求返回错误、超时或输出不是合法 JSON
- **THEN** 消息正常显示，界面不出现搜索气泡与错误提示

#### Scenario: 关键词不合法视为未命中
- **WHEN** 模型返回的关键词为空、超过 3 个或单个超过 20 个字符
- **THEN** 该次结果按未命中处理，不出现搜索气泡

### Requirement: 跨对话本地检索

应用 SHALL 在设备本地按识别出的 1–3 个关键词检索全部未删除对话中的未删除消息，MUST NOT 将整段会话内容发送给模型。结果 MUST 至少命中一个关键词，按命中关键词数量从多到少、同数量按消息时间从新到旧排序，最多返回 5 条，并 MUST 排除作为搜索请求的当前消息。

#### Scenario: 跨会话命中
- **WHEN** 其他对话中存在包含该关键词的消息
- **THEN** 该消息出现在检索结果中，并带上所属对话标题

#### Scenario: 排除请求消息与已删除内容
- **WHEN** 检索关键词也出现在当前搜索请求消息或已删除的消息中
- **THEN** 这些消息不出现在结果里

#### Scenario: 排序与数量上限
- **WHEN** 命中消息超过 5 条
- **THEN** 只展示前 5 条，命中关键词更多的排在前面

#### Scenario: 没有命中
- **WHEN** 所有对话中都没有包含关键词的消息
- **THEN** 气泡显示「未找到相关消息」，且不提供可点击条目

### Requirement: 结果气泡与跳转

搜索建议气泡 SHALL 以「搜索到如下消息：」开头列出结果，每条结果 MUST 是可点击的超链接并显示所属对话标题与消息摘要。用户点击后，应用 MUST 切换到对应对话、滚动到该消息并短暂高亮该消息气泡。

#### Scenario: 展示可点击结果
- **WHEN** 检索返回至少一条结果
- **THEN** 气泡逐条展示会话标题与消息摘要，每条都可点击

#### Scenario: 点击跳转并定位
- **WHEN** 用户点击某条搜索结果
- **THEN** 界面切换到该消息所在的对话，滚动到该消息并短暂高亮气泡

#### Scenario: 目标已不存在
- **WHEN** 用户点击结果时该对话或消息已被删除
- **THEN** 应用不切换对话，并提示目标已不存在

### Requirement: 结果的临时性与失效

搜索结果气泡 SHALL 只存在于内存，MUST NOT 写入会话文件、快照、导出结果或局域网同步载荷，应用重启后 MUST NOT 恢复。结果 MUST 与触发搜索的消息内容版本绑定，该消息被编辑或删除后结果 MUST 失效。

#### Scenario: 重启后不恢复
- **WHEN** 用户在搜索结果出现后重启应用
- **THEN** 该搜索结果不再出现

#### Scenario: 请求消息被编辑后失效
- **WHEN** 搜索结果存在时触发搜索的消息被修改或删除
- **THEN** 搜索结果气泡消失

#### Scenario: 不进入同步与导出
- **WHEN** 用户导出对话或与另一台设备同步
- **THEN** 传输内容不包含任何搜索结果气泡

#### Scenario: 切换对话后仍可见
- **WHEN** 用户在结果未处理时切到其他对话再切回
- **THEN** 该搜索结果仍然显示

### Requirement: 搜索请求消息照常保存

用于触发搜索的用户消息 SHALL 作为普通消息保存并出现在会话记录中；搜索只影响建议气泡，MUST NOT 修改、删除或隐藏该消息。

#### Scenario: 请求消息保留
- **WHEN** 用户发送一条被识别为搜索意图的消息
- **THEN** 该消息仍按普通消息出现在会话历史中

#### Scenario: 检索失败不影响消息
- **WHEN** 本地检索没有结果或发生异常
- **THEN** 搜索请求消息仍正常保存并显示
