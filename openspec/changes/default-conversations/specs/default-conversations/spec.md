# Spec Delta

## Purpose

定义初次安装时的默认对话、默认选中的对话，以及后续启动恢复最后使用对话的行为，确保用户打开应用即可在“草稿”中开始记录。

## ADDED Requirements

### Requirement: 首次安装默认对话

记录目录中没有任何文件时，应用 SHALL 创建“极其重要”和“草稿”两个默认对话；目录中只要存在任何文件（包括旧笔记、已删除对话留下的记录文件），应用 MUST NOT 创建默认对话。

#### Scenario: 首次打开应用
- **WHEN** 用户首次安装、选择一个空目录进入应用
- **THEN** 对话列表显示“极其重要”和“草稿”两个对话
- **AND** 两者都可以像普通对话一样收发消息、重命名与删除

#### Scenario: 已有记录的目录不创建
- **WHEN** 用户重装后选择包含笔记文件的目录
- **THEN** 应用不创建默认对话

#### Scenario: 重命名或删除默认对话后重装
- **WHEN** 用户重命名或删除默认对话，卸载重装后重新选择原目录
- **THEN** 目录中仍有记录文件，应用不创建默认对话

#### Scenario: 删除后不自动重建
- **WHEN** 用户删除“极其重要”和“草稿”后重新打开应用
- **THEN** 应用不自动重新创建这两个对话

### Requirement: 默认选中草稿

首次创建默认对话后，应用 MUST 默认选中“草稿”。

#### Scenario: 首次进入即为草稿
- **WHEN** 默认对话创建完成
- **THEN** 当前打开的对话是“草稿”

### Requirement: 沿用最后使用的对话

后续启动时，应用 MUST 恢复最后一次打开的对话。

#### Scenario: 重启后恢复
- **WHEN** 用户切换到“极其重要”后关闭并重新打开应用
- **THEN** 当前打开的对话仍是“极其重要”
