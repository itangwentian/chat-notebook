# Spec Delta

## Purpose

定义本地消息附件在对话删除及跨对话复用时的文件保留与清理规则，避免长期残留无引用附件，同时确保仍被其他对话使用的文件不会被误删。

## ADDED Requirements

### Requirement: 删除对话后清理无人引用的附件

删除对话成功持久化后，系统 SHALL 删除该对话引用且未被任何其他未删除对话引用的附件文件。引用按附件相对路径判断；其他未删除对话中已软删除但仍保存在记录中的消息 SHALL 继续计为引用。

#### Scenario: 删除对话后清理仅由该对话使用的附件
- **WHEN** 用户删除对话，且其中一附件路径未被其他未删除对话引用
- **THEN** 对话记录删除成功后，该附件文件被删除

#### Scenario: 其他对话仍引用相同附件
- **WHEN** 用户删除对话，且另一未删除对话的消息引用相同附件路径
- **THEN** 该附件文件保留，另一对话中的附件仍可读取

#### Scenario: 其他对话的软删除消息仍引用附件
- **WHEN** 用户删除对话，且另一未删除对话中已软删除的消息仍引用该附件路径
- **THEN** 该附件文件保留

#### Scenario: 删除对话中的多个消息共享一个附件路径
- **WHEN** 被删除对话中多条消息引用同一附件路径，且其他对话均未引用
- **THEN** 清理过程只删除该文件一次

### Requirement: 附件清理失败时明确报告

对话记录持久化删除后，若删除无人引用的附件文件失败，系统 SHALL 向调用方报告清理失败，且 MUST NOT 将失败表述为附件已清理成功。

#### Scenario: 附件文件删除失败
- **WHEN** 对话已成功删除，但记录目录拒绝删除某个无人引用的附件文件
- **THEN** 对话删除状态保持已持久化，调用方收到明确的附件清理失败结果
