# Spec Delta

## Purpose

保证笔记内容不离开设备，应用不保存第三方模型凭据，并在升级后清理历史外部 AI 接入留下的配置与密钥。

## ADDED Requirements

### Requirement: 应用不接入外部 AI

应用 MUST NOT 调用任何外部大模型或 AI 接口，且在没有网络连接时仍可完成消息、整理与提醒的全部本地功能。

#### Scenario: 离线使用核心功能

- **WHEN** 设备处于无网络状态
- **THEN** 用户可以发送消息、整理会话并创建日程提醒
- **AND** 应用不出现等待 AI 响应或网络失败的提示

#### Scenario: 发送消息不触发外部分析

- **WHEN** 用户发送一条消息
- **THEN** 应用不向任何外部服务发送该消息内容

### Requirement: 设置页不提供模型配置

设置页 MUST NOT 展示模型列表、默认模型、模拟模式、API Key 输入或连接测试入口。

#### Scenario: 打开设置页

- **WHEN** 用户进入设置页
- **THEN** 页面只展示本地功能与数据相关设置
- **AND** 页面不包含任何模型或 API Key 相关控件

### Requirement: 清理历史模型配置与密钥

应用启动时 MUST 删除本机保存的模型配置，并删除安全存储中的 API Key；清理失败不得阻断应用启动。

#### Scenario: 升级后启动

- **WHEN** 已安装过旧版本的用户首次启动新版本
- **THEN** 本机模型配置与 API Key 被删除
- **AND** 应用正常进入会话列表

#### Scenario: 清理失败

- **WHEN** 删除历史配置或密钥时发生异常
- **THEN** 应用记录失败但不崩溃
- **AND** 后续启动会再次尝试清理

### Requirement: 同步不传输模型设置

局域网同步载荷 MUST NOT 包含模型配置、API Key 或模型选择设置，只同步笔记、附件、整理文档与删除信息。

#### Scenario: 设备间同步

- **WHEN** 两台设备通过局域网同步笔记
- **THEN** 请求与响应中不包含模型配置或密钥字段
- **AND** 笔记数据仍按既有规则完成同步

### Requirement: 旧记录文件兼容读取

读取包含模型配置字段的旧记录文件时，应用 MUST 忽略这些字段并继续加载其余数据。

#### Scenario: 打开旧记录文件

- **WHEN** 应用读取旧版本写入、包含模型配置字段的文件
- **THEN** 应用忽略模型配置字段
- **AND** 会话消息、整理文档与提醒正常显示
