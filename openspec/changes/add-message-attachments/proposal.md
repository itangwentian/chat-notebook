# Proposal

## Why

输入栏的图片与语音入口目前仍是禁用占位（`ChatScreen` 中 `image_button`、`voice_button` 均为 `enabled = false`），用户只能记录文字，无法随手保存截图、照片或语音备忘。需要把这两个入口补成可用的附件能力：图片从本地相册浏览添加，语音点击即录、停止即成为附件，附件可与文字一起合并发送和展示，并沿用现有的本地快照持久化与卸载后保留策略。

## What Changes

- 图片附件：点击附件图标打开系统照片选择器，支持一次选择多张本地图片；选中的图片进入输入栏上方的草稿附件区，可逐张移除。
- 语音附件：点击语音按钮申请录音权限并开始录音，按钮切换为停止；停止后录音作为附件加入草稿区，可移除，可追加文字后再发送。
- 合并发送：一条消息 SHALL 同时承载文字、多张图片和录音；只发附件不写文字也可发送，两者都为空时保持不可发送；发送前仍要求已选择记录目录。
- 展示：气泡内先显示文字，再显示图片缩略图与可播放的语音条目；图片可点开大图查看，语音可播放/停止并显示时长；文件缺失时显示明确占位。
- 持久化：附件二进制写入用户所选记录目录的 `attachments/` 子目录，版本化快照只保存相对路径与元数据；Room 增加附件列并显式迁移，旧快照校验和保持可解析。
- 非目标：语音转文字、图片 OCR、裁剪/压缩编辑、附件参与 AI 整理内容、附件参与消息合并、附件云同步。

## Capabilities

### New Capabilities

- `message-attachments`：图片与语音附件的选择/录制、草稿增删、与文字合并发送、气泡内展示与播放、文件持久化与恢复。

### Modified Capabilities

无。既有 `chat-sessions` 的两层圆角输入栏与键盘贴合约束保持不变；其“附件与语音入口禁用”的占位描述由本变更的新能力替换为可用交互。

## Impact

- 代码：`ChatScreen` 输入栏与气泡渲染、`ChatViewModel` 草稿附件与录音状态、`ChatSessionService.send` 的发送规则、`ChatRepository` 新增附件写入接口、`Snapshot`/`SessionFileCodec`/`AttachmentStore`、`RecordDatabase`（v7 → v8 迁移）、`AndroidManifest` 录音权限与中文资源。
- 数据：快照新增可选附件列表字段，空值不参与编码以兼容既有校验和；附件文件新增于所选目录的 `attachments/` 子目录，软删除消息不删除附件文件。
- 验证：新增单元测试、Room 迁移测试与 Compose/模拟器检查；无法执行的设备项需如实记录。
